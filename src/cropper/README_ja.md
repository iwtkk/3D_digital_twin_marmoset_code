
# ペア画像 同期クロッパー（Paired Image Cropper）

## できること
- 対応する2枚の画像ペアに対して、片方で選んだクロップ矩形をもう片方にも同じように適用します。
- 次の画像に移っても**直前のクロップ「サイズ」**（幅×高さ）を保持します。
- セッションをまたいでもサイズを復元できるよう、`paired_cropper_state.json` に保存されます。

> 画像サイズがペアで異なる場合は `--relative` オプションを使うと、A画像側の座標を**相対座標**に変換してB側に適用します。

## 使い方
Python3 と OpenCV (`pip install opencv-python`) を用います。

### 1) ディレクトリ同士でペアにする（ファイル名が同じ前提）
```
python paired_cropper.py --dir-a path/to/A --dir-b path/to/B --out out_dir
```

### 2) CSVで任意のペアを指定する
`pairs.csv` の各行に `A画像パス,B画像パス` を書きます（ヘッダ不要）。
```
python paired_cropper.py --map pairs.csv --out out_dir
```

### 3) 画像サイズが異なるペアにも相対適用する
```
python paired_cropper.py --dir-a A --dir-b B --out out_dir --relative
```

### オプション
- `--exts ".jpg,.png"`: `--dir-a/--dir-b` 使用時に読み込む拡張子を指定（省略可）
- `--start N`: N番目（0始まり）から開始
- `--relative`: Aで決めた矩形を相対化してBへ適用（サイズの異なるペアに便利）

出力先は `out_dir/A/` と `out_dir/B/` です。ファイル名はA側の元ファイル名（拡張子除く）に合わせて `.png` で保存します。

## ウィンドウ操作
- **マウス左ドラッグ**: 矩形を作成/更新  
- **Enter または 'n'**: クロップして保存 → 次のペアへ  
- **'b'**: 前のペアへ戻る（保存しない）  
- **'c'**: 矩形をクリア  
- **'r'**: 直前の「サイズ」を中央に再配置（位置はリセット）  
- **'f'**: 固定サイズモード切替（直前サイズで固定・クリック位置を左上に配置）  
- **'h'**: ヘルプの表示/非表示  
- **'q' または ESC**: 終了  

> 直前のクロップサイズは `paired_cropper_state.json` に保存/復元されます。複数回起動しても同じサイズを初期値として使えます。

## よくある質問
- **B側の画像サイズが違い、同じ座標だとはみ出します。**  
  → `--relative` を使ってください。A側での矩形を相対化（0〜1）し、B側のサイズに合わせて再計算してから切り出します。

- **固定サイズでポンポン切り取りたい。**  
  → キー `f` で固定サイズモードに入ると、クリックした位置を左上として直前サイズの矩形が即配置されます。

- **マッチしないファイルがある。**  
  → `--dir-a/--dir-b` の場合は拡張子を除いた「同名」ファイルのみペア認識します。CSV指定なら自由なペアリングが可能です。
